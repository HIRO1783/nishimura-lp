FAQ

よくある質問

生成AI研修の費用はどのくらいですか？
+

社内の勉強会1回は5万円〜、研修は15万円〜が目安です（税別）。人数・時間・内容を伺って、お見積りします。

条件が合えば、国の助成金（人材開発支援助成金）が使える場合があります。

ChatGPTを会社で使うと、情報が漏れませんか？
+

入れてよい情報・入れてはいけない情報を決めるところから、一緒に始めます。

お使いのプランで、入力した内容がAIの学習に使われない設定になっているかも確かめます。

Excelのマクロ作成だけでも頼めますか？
+

はい。1本5万円〜（税別）が目安です。使い方・直し方の説明書を付けます。

納品後1か月は、作った物の不具合を無料で直します。作業の中身の変更や機能の追加は、別にお見積りします。

AIについて知識がなくても大丈夫ですか？
+

はい。専門用語はできるだけ使わず、御社の実際の仕事を題材にご説明します。

AIを入れなくても相談できますか？
+

はい。AIを入れること自体は目的にしていません。Excelや手順の見直しで済む場合は、そうお伝えします。

個人事業主でも相談できますか？
+

はい。おひとりで事業をされている方のご相談もお受けしています。1つの作業だけのご依頼でも構いません。

どんな業種でも相談できますか？
+

はい、業種は問いません。会社やお店の事務、工場の日報・手順書づくりなども、ご相談ください。

物流・倉庫・運送の会社様には、専用のページがあります。

尼崎・西宮・大阪に来てもらえますか？
+

はい。尼崎を拠点に、西宮・伊丹・宝塚・芦屋・大阪など、京阪神へうかがいます。

オンライン（Zoom・Google Meetなど）なら、全国からご相談いただけます。

生成AIセミナーの講師を頼めますか？
+

はい。商工会議所・業界団体・企業の勉強会で、60分のスライド講義をお引き受けします。業種は問いません。

テーマは、入門・文章・発信・仕組み化・AIの使い分け・応用から選べます。日程・費用はご相談ください。

ChatGPT以外のAIにも対応していますか？
+

はい。ChatGPT・Claude・Geminiなどから、仕事の中身と社内の環境に合わせて選びます。すでにお使いのツールを生かす方法もご提案します。

単発の相談だけでも大丈夫ですか？
+

はい。続けてのご契約が前提ではありません。1回のご相談だけでも構いません。

無料相談で、その場で契約を迫られませんか？
+

いいえ、その場での契約を求めることはありません。持ち帰ってご検討いただけます。お断りいただいても構いません。

頼めば、必ず効率化できますか？
+

成果を保証するものではありません。仕事の中身や使い方によって、効果は変わります。

そのため、1つの作業で小さく試し、確かめてから広げる進め方をおすすめしています。
